TUTORIEL / 001

Lier Discord à FiveM

Rétablis la liaison entre Discord et FiveM en suivant ces trois étapes, dans l'ordre.

DISCORD + FIVEM
Avant de commencer

Ferme FiveM. Si tu rencontres déjà des erreurs d'autorisation, suis la procédure complète ci-dessous.

01
ÉTAPE 1

Réinitialiser l'autorisation d'application

DISCORD
  1. Assure-toi que FiveM est fermé.
  2. Ouvre Discord et accède aux Paramètres utilisateur (roue dentée).
  3. Ouvre l'onglet Applications autorisées.
  4. Repère FiveM, puis clique sur Retirer l'autorisation si l'application apparaît.
  5. Ferme complètement Discord, également depuis la zone de notification de Windows.
02
ÉTAPE 2

Vérifier les permissions de Discord

WINDOWS

Vérifie que Discord ne démarre pas en mode administrateur :

  1. Fais un clic droit sur l'icône ou le raccourci Discord puis sélectionne Ouvrir l'emplacement du fichier.
  2. Fais un clic droit sur le raccourci Discord puis choisis Propriétés.
  3. Dans l'onglet Raccourci, ouvre Avancé….
  4. Assure-toi que l'option Exécuter en tant qu'administrateur est décochée. Valide les changements si nécessaire.

Selon la version de Windows, vérifie aussi l'onglet Compatibilité du programme Discord si cette option n'est pas visible sur le raccourci.

03
ÉTAPE 3

Relancer les applications dans le bon ordre

CONNEXION
  1. Lance Discord en premier et assure-toi d'être connecté à ton compte.
  2. Lance FiveM en second.
  3. Reviens sur Discord, attends la fenêtre d'autorisation de FiveM et autorise l'accès si elle apparaît.

Si aucune fenêtre ne s'affiche, cela ne signifie pas forcément que la liaison a échoué : relance une connexion au serveur et vérifie si le problème initial persiste.

Connexion Discord / FiveM0 / 3 étapes terminées
TUTORIEL / 002

Vider le cache FiveM

Supprime les fichiers temporaires pour résoudre certains problèmes de chargement ou d'affichage.

WINDOWS
Important : conserve « game-storage »

Ferme FiveM avant le nettoyage. Vérifie que tu es bien dans le dossier de FiveM et non dans celui de GTA V. Supprimer certains fichiers de données peut réinitialiser des réglages locaux ou entraîner un nouveau téléchargement.

EXPLORATEUR WINDOWS / CHEMIN VISUELFiveM Application Data → data → préserver game-storage
01
ÉTAPE 1

Fermer FiveM

Quitte entièrement FiveM et attends que le programme soit fermé avant de toucher à ses fichiers.

02
ÉTAPE 2

Ouvrir le dossier FiveM

Sur ton bureau, fais un clic droit sur l'icône FiveM puis sélectionne Ouvrir l'emplacement du fichier.

03
ÉTAPE 3

Accéder à FiveM Application Data

Dans l'emplacement ouvert, entre dans FiveM Application Data si ce dossier est présent (le nom peut varier selon l'installation).

04
ÉTAPE 4

Nettoyer les dossiers de diagnostics

Supprime les dossiers crashes et logs s'ils existent. Ils contiennent notamment des rapports de plantage et des journaux utiles au diagnostic : conserve-les si le support t'a demandé des logs.

05
ÉTAPE 5

Vider le dossier data

Ouvre data. Pour un nettoyage approfondi, supprime les éléments temporaires de ce dossier en conservant impérativement le dossier game-storage.

Un nettoyage ciblé des seuls dossiers de cache est préférable en première intention. Ne supprime pas les dossiers que tu ne reconnais pas sans en avoir fait une copie de sauvegarde.

06
ÉTAPE 6

Relancer FiveM

Rouvre FiveM. Le premier lancement peut être plus long, car certains fichiers temporaires seront recréés automatiquement.

Nettoyage local / Aucune action serveur0 / 6 étapes terminées
